# Privacy

| Data | Default |
|---|---|
| Evaluation and verification records | shared |
| Derived `task_label` (not the user's sentence) | shared |
| Outcome reports | shared when the user gives one |
| Raw task sentence | **opt-in only** — task text can reveal private projects |
| API keys, user code or files, environment details | **never** |

Contributor identity is an anonymous keypair created on install. A GitHub link is optional.

User-facing wording lives in `skills/skill-scout/references/privacy-notice.md`. It must match this table.
