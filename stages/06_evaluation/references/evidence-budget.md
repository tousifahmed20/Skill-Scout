# Evidence budget (per candidate)

| Evidence | Limit |
|---|---|
| `SKILL.md` | full |
| File tree of the skill folder | full |
| Scripts | up to 300 lines total; files referenced in SKILL.md first |
| References referenced in SKILL.md | first 100 lines each, at most 3 files |
| README | first section only, at most 80 lines |
| Issue threads that mention the skill | last 10: title plus the final 3 comments |

Hard cap: about 6,000 input tokens. When over the cap, cut in reverse order of this table. Never send a whole repo.
